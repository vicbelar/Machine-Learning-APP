# Rationale · M02

**One choice of our group that I support / doubt:** We record the EMG over Bluetooth into a web page (Captura ML) instead of sending it from the ESP32 over the internet, and the page packs the data in a fixed, open format: CSV files with every column described in DATA-DICTIONARY.md, a metadata file, and a quality report.

**Why:** Recording does not need Wi-Fi or a server, and the data stays on the phone until we export it. The format does not depend on Edge Impulse, if we train the model somewhere else, or use the page for another project, the same files still work. Clear metadata and open formats are what make data reusable. (At the end we didn't use Edge Impulse for practical work)

**One source I found:** Wilkinson MD, Dumontier M, Aalbersberg IJ, et al. The FAIR Guiding Principles for scientific data management and stewardship. Scientific Data 3:160018, 2016. https://doi.org/10.1038/sdata.2016.18

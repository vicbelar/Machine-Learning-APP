# Rationale · M04

**One choice of our group that I support:** testing the model only on sessions S05 and S06, recorded on another day with new electrodes, and never using them to choose features or the model.

**Why:** in PERLA, a child uses the system on a different day each time, and the electrodes are never placed in exactly the same spot. If we mixed windows of the same session in training and test, the model would recognize the session and not the contraction, and the score would look better than it is. Keeping whole sessions apart gives a more honest number for the 75 % goal.

**One source I found:** Riascos Salas J, Molinas M, Lotte F. Machine learning methods for BCI: challenges, pitfalls and promises. ESANN 2024. https://www.esann.org/sites/default/files/proceedings/2024/ES2024-4.pdf

# Cue

`cue-video.mp4` (1 minute, 8 seconds): a video of the app Captura ML during a recording. It shows the cue of the first trials; a full recording repeats the same trial 5 times (55 s). Each trial:
Reposo (4 s) → Prepárate (1 s, yellow) → CONTRACCIÓN SOSTENIDA (3 s, green) → Reposo (3 s), with a beep at each change.
The person watches this same timer in every recording.

How to make it: open the app, start the Simulador, open a session, press Grabar and record the screen
(Windows: Win + Alt + R with the Xbox Game Bar, or the Snipping Tool in video mode). Delete that test recording afterwards.
